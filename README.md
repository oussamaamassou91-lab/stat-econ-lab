# STAT-ECON LAB (offline)
Open stat-ecolab.html in any browser. No server, no CDN, no network calls.
Implemented (JavaScript engine): import CSV/TSV/TXT/JSON/paste, data dictionary, descriptives, Pearson/Spearman, Jarque-Bera, one-sample and Welch t-test, chi-square, one-way ANOVA (Levene, Welch, Kruskal, Bonferroni post-hoc), OLS (BP, DW, VIF, JB), logistic regression, decision engine, R/Python code generation, table export (CSV/Markdown/LaTeX/HTML), projects (localStorage), HTML report.
Not included: Pyodide/WebR runtimes (tens of MB; require downloading once from their official releases into /libs). Panel, time series, survival, IV not implemented.
